# B站视频自动上传（Bilibili Auto Uploader）

一个在 Windows 上运行的图形化软件，定时把指定文件夹里新出现的视频自动上传到 B 站。

## 功能

- **定时上传**：每天按设定时刻自动扫描文件夹并上传新视频。
- **差异去重**：自动记录已上传文件，只上传新视频，不重复。
- **多文件合并**：同一天的多个视频可作为一个稿件多分P上传。
- **大文件自动拆分**：单个文件过大时自动切成多段，作为一个稿件多分P。
- **高度自定义**：监控目录、定时规则、标题命名模板、简介、标签、封面、分区、发布方式、清理策略等均可配置。
- **多种发布方式**：直接发布 / 延迟发布（上传后 N 小时）/ 定时到指定时刻。
- **自动更新**：启动时检查 GitHub 最新版本，提示下载更新。
- **界面**：简洁现代的淡蓝 + 深色主题，系统托盘常驻。

## 快速开始

### 方式一：使用打包好的 exe（推荐）

到 [Releases](../../releases) 下载最新版 `BiliAutoUpload.exe`，双击运行即可（无需安装 Python）。

### 方式二：从源码运行

环境要求：Python 3.12+，并安装 [ffmpeg](https://ffmpeg.org/)（加入系统 PATH，或放到 `resources/ffmpeg/bin/` 下）。

```bash
pip install -r requirements.txt
python main.py
```

## 使用说明

1. **登录**：进入「登录」页，扫码登录（或粘贴 Cookie）。
2. **设置**：添加监控文件夹、设定定时规则、命名模板、分区、发布方式等。
3. **运行**：点击「立即运行一次」手动触发，或等定时任务自动执行。
4. **历史**：在「历史记录」页查看上传结果。

> 上传成功后的本地文件默认移动到 `auto_archived` 归档文件夹（可在设置里改为删除或不处理）。

## 打包

```bash
pip install pyinstaller
python build/build.py
```

产出 `dist/BiliAutoUpload.exe`（已内置 ffmpeg）。

## 免责声明

本工具使用 B 站的内部接口实现上传，B 站随时可能调整接口导致功能失效。请遵守 B 站相关规定，合理使用。

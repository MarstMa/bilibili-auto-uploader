# 开发需求（需求基线）

> 本文档是需求的唯一事实来源。需求变更需先在此更新并知会用户确认。

## 一、背景
面向 Windows 11 的图形化软件，由不懂代码的用户使用。目标是：定时把指定文件夹里新出现的视频自动上传到 B 站，减少人工搬运工作。

## 二、核心功能

1. **定时上传**：每天在设定时间自动扫描监控文件夹，把新出现的视频上传到 B 站。
2. **差异比对（去重）**：自动记录已上传文件，只上传新文件，避免重复上传。
3. **自动清理**：上传成功后处理本地原文件（默认归档，可切换删除 / 不处理）。
4. **自动合并**：同一天多个新视频，作为一个稿件的多个分P上传（不物理合并）。
5. **自动拆分（分P）**：单个文件过大时，自动切成多段，作为一个稿件的多个分P上传。

## 三、已确认决策

| 事项 | 决策 |
|---|---|
| 文件清理 | 默认「移动到归档文件夹」，可切换「永久删除」「仅记录不处理」 |
| 登录方式 | 扫码 + Cookie 两种都支持 |
| 发布方式 | 可配置：直接发布 / 延迟发布（上传后 N 小时）/ 定时到指定时刻（如每天 20:00）；默认「延迟发布」 |
| 多文件处理 | 默认「一个稿件多分P」；单文件过大物理拆分分P |

## 四、可自定义项（最大化自定义）

- 监控文件夹路径（可多个）
- 定时规则（每天一个或多个时间点）
- 标题命名模板 + 分P标题模板（变量见技术设计规范）
- 简介模板、标签、封面
- 分区（tid）、版权（原创/转载）、转载来源
- 多文件策略（多分P / 物理合并 / 独立上传）
- 拆分阈值（单文件大小上限）
- 发布方式（直接发布 / 延迟发布 / 定时到指定时刻）
- 清理策略（归档 / 删除 / 不处理）及归档目录
- 开机自启、常驻托盘、上传并发数、重试次数

## 五、界面要求
- 图形化软件，简洁直观、现代化。
- 配色：淡蓝色 + 深色主题。
- 页面：仪表盘（状态/立即运行）、设置、登录、历史记录。
